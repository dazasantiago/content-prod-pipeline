## Angle / thesis
HyperFrames bets that video is written, not edited — and that changes who gets to produce content,
not just how fast.

---

## Scene 1 — Hook

`[ON SCREEN — CAM]`
This video you're watching right now? Nobody edited it.

`[ON SCREEN — SCR: the composition's HTML file in the editor]`
There's no timeline. There's no track. There's this — an HTML file.

And I want to show you what breaks in your head when you realize that's enough.

## Scene 2 — The real bottleneck

`[ON SCREEN — CAM]`
Here's what nobody tells you when you start making videos.

Recording isn't the hard part. You can record something decent on your phone today.

`[ON SCREEN — GEN: an editor pushed aside by an AI logo]`
The hard part is everything after. You cut, you rearrange, you realize the second half doesn't land,
you rewrite one line — and now the cut you spent two hours on is wrong.

So you either publish something worse than what you wanted, or you don't publish.

**Sources:** hn:47797513

## Scene 3 — Same input, same output

`[ON SCREEN — CAM]`
HyperFrames renders HTML and CSS straight to an MP4.

`[ON SCREEN — SCR: the render command running twice, producing identical files]`
And the important word isn't HTML. It's deterministic. Same input, same output. Every time.

That's the whole thing. That's why this matters.

Because the moment your video is deterministic, it's not a craft anymore. It's a build. You change a
line, you re-render, you get exactly the video that line describes.

**Sources:** hn:47797513, discovered:https://hyperframes.app

## Scene 4 — Anything that writes HTML

`[ON SCREEN — CAM]`
And if a video is just code that compiles —

`[ON SCREEN — GFX: three steps chained, script → HTML → MP4]`
then anything that can write HTML can make one.

Including the thing you're probably already using to write code.

**Sources:** hn:47797513

## Scene 5 — Where it still hurts

`[ON SCREEN — CAM]`
I'm not going to pretend this is free.

If you've never touched front-end, the learning curve is real. You're not learning a video tool,
you're learning a layout engine.

`[ON SCREEN — BROLL: a long render progress bar crawling]`
And long compositions take real time to render. This isn't instant.

There's also a fair criticism going around, and I think it's right: this is great for motion
graphics and it does not replace editing real footage. If your video is you talking to a camera for
twenty minutes, this doesn't save you.

**Sources:** discovered:https://hyperframes.app

## Scene 6 — Payoff and close

`[ON SCREEN — SCR: the same HTML file from Scene 1, same framing]`
But go back to what I opened with.

`[ON SCREEN — CAM]`
Nobody edited this video. And now you know what that actually means — not that it was easy, but that
it was repeatable.

If video becomes code, then video gets versioned, reviewed, and automated like code.

Which leaves one question I genuinely don't know the answer to: what happens when the thing
producing the video isn't a person?

Tell me what you'd automate first.
